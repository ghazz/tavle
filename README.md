# Tavle

An at-a-glance display and keypress layer for small always-on machines:
modules publish small pieces of information, renderers of any weight
(terminal, Markdown, graphical) show them, and buttons run predefined
tasks.

## A personal project

Tavle is built for one household's own machines. It is shared as it is,
without support, a release schedule or a promise that it fits anyone
else's setup. The working code is not published here yet; this
repository holds the goals (`GOALS.md`) and the fixed constraints
(`docs/core-requirements-fixed-constraints.md`).
