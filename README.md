# Tavle

An at-a-glance display and keypress layer for small always-on machines:
modules publish small pieces of information, renderers of any weight
(terminal, Markdown, graphical) show them, and buttons run predefined
tasks.

Status: the restrictions are agreed (`GOALS.md`); the design is being
rebuilt on existing systems and standards. No implementation yet.

Contact and User-Agent identification: https://github.com/ghazz/tavle
